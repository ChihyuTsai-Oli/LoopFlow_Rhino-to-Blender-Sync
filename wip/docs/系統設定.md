- **設定與即時檔**：已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2B/`。未存檔即停。

## Build 與 Release（對齊 LoopFlow 2.0）

尚未建置；G02 才做。規則先鎖定如下。

### 安裝格式

- 主格式：`.yak`（Rhino 8 Package Manager）。GitHub Release 與 Package Manager **同一份** `.yak`，另附 checksum。不做 RHI。
- **只包 Rhino**：正式指令、`.rhp`、產品工具列 RUI。
- **不進 yak**：Blender Sync add-on、內嵌 `import_3dm`、Toolkit。Blender 端由 GitHub Release／README 安裝。
- Package Manager **說明**必須放本 repo GitHub 連結，指向 Blender 安裝方式。
- 畫面名稱：**`loopflow Rhino to Blender Sync`**。檔名型式對齊 `loopflow-2.0.7-rh8_0-win.yak`（例 `loopflow-rhino-to-blender-sync-3.0.0-rh8_0-win.yak`）。
- 開發期仍用 ScriptEditor＋repo；進包後按鈕打正式 `R2B_*`。

### GitHub tag（不覆寫）

| tag | 意義 |
|---|---|
| `v2.0.0` | 已發布 2.x；永不移動 |
| `v3.0.0` | 第一次公開 3.0 功能版；永不移動、不覆寫 |
| `v3.0.1`… | 之後清單／工具列／說明連結等修補；各 tag 亦不覆寫 |

同一個 tag 代表該次**整份 repo**（含 GitHub 上的 Blender 原始碼）；yak 仍只含 Rhino。

公開中英使用說明改寫等 **R2O 程式也完成後再一起寫**。現有 `docs/README.md` 入口可先開，內連現行指南。

### 本機「文件\LoopFlow」戳記

對齊 LoopFlow 2.0：若 yak 日後把官方檔拷到 `%USERPROFILE%\Documents\LoopFlow\`（或產品子資料夾）：

- 戳記＝套件版號；版號相同且已有檔則不蓋。
- 版號不同或沒有戳記：重拷官方檔（使用者多的檔不刪）；這次有拷才開資料夾。
- 那不是專案工作資料夾。工作仍以已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2B/` 為準。

### 建置路徑（G02 時再核對）

對齊 LoopFlow：Rhino 8 Script Editor `*.rhproj` → `RhinoCode.exe project build` → `.rhp` → `yak.exe build`。指令 `language` 必須是物件，不可字串 `"python3"`。產品 RUI 另存，不要用 RhinoCode 自動產生那份去改使用者工具列套件。
