## 執行時路徑

- **設定與即時檔**：已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2B/`。未存檔即停。
- 測檔環境變數：`LOOPFLOW_R2B_WORKFILES_ROOT`（雙機路徑見工作區 `工作檔路徑.md`）。**不**用 Dropbox `exchange/` 當執行時根。
- Consumer 找專案：指標檔預設＋手動覆寫（XF-ED-04＝C）。指標可在 `%APPDATA%`；語系等電腦偏好也放 AppData，不進專案設定根。
- 即時檔不提交 Git。
- 程式不寫死某台電腦的 Dropbox 絕對路徑。

## 開發測試入口

### Rhino

- 按鈕巨集：`rhino指令.md` → `wip/src/rhino/entrypoints\`（Models／Camera／Light／Open 已接）。
- 已凍結指令：`RBModels`、`RBObjects`、`RBCamera`、`RBCameraPush`、`RBLight`、`RBLightPush`、`RBOpen`。

### Blender（測試用 Sync add-on）

- **執行環境（雙機相同）**：Portable `E:\blender-5.2.1_wip\`（`LOOPFLOW_BLENDER_EXE`＝其下 `blender.exe`；見工作區 `工作檔路徑.md`）。
- **本機設定根**：`E:\blender-5.2.1_wip\portable\`（與日常 2.x `%APPDATA%` 隔離）。**不要**把開發原始碼主檔寫在此目錄（換機不同步）。
- **原始碼唯一來源**：`wip/src/blender/loopflow_r2b_sync_dev/`（Git）。以 junction 掛到  
  `E:\blender-5.2.1_wip\portable\scripts\addons\loopflow_r2b_sync_dev`。  
  腳本：`wip/tools/link_dev_addon.ps1`（換機 pull 後若無聯結則重跑）。
- **package ID 與 2.x 不同**，不覆蓋已發布 `LoopFlow_import_3dm`／2.x Toolkit。**ToolBox** 另包 `loopflow_toolbox`，不進 yak。
- `bl_info` 顯示名：**`LoopFlow Rhino to Blender Sync`** **0.0.19**；author `Chihyu Tsai`；Blender **5.2.1**。正式 zip **沒有** `blender_manifest.toml`（走傳統 Add-ons，避免 Extensions 在 Dropbox 上 `@` 改名失敗）。zip 內附 `foundation`。內層 `import_3dm` 也沒有清單檔。
- N-Panel：標籤 **`LoopFlow`**。3D 視窗 bar **`Rhino to Blender Sync`**（已凍結）。**Models／Camera／Light／Open 已接**；各按鈕有英文懸停。**Open / Health** 懸停＝摘要、左鍵開設定根。**Open Docs** 開 GitHub 文件入口（`docs/README.md`，再進中／英使用說明）。Shader Editor 另有 bar **`Box Projection`**（**家中通過**：Load PBR Maps、World／Object、幾何法線、Blend 0 轉 45° 不發黑、新建節點寬 ×1.5；內建 Node Group、GPU 可跑；不進 3D Sync 面板）。**ToolBox** 獨立 add-on、同一標籤、bar **`ToolBox`**（不進 yak；見 `toolbox/`）。
- **作業資料夾**：與 `.3dm`／`.blend`／`_LoopFlow_Config` **同層**；解析 `live/camera.json`、`light.json`、`models/R2B.3dm`、`models/R2B_Objects.3dm`。
- Models 兩組：**Sync Models／Update Models**＝有材質（對 `RBModels`）；**Import Objects**＝無材質（對 `RBObjects`；檔案總管選 3dm）。使用 **Sync 內嵌** `import_3dm` fork。**不必**再啟用獨立「Import Rhinoceros 3D」。

## Build 與 Release（對齊 LoopFlow 2.0）

G02 yak **`3.0.0` 已上架**（GitHub Release 與 Package Manager）。來源：`wip/packaging/g02-spike/`。步驟見該目錄 `README.md`。

### 安裝格式

- 主格式：`.yak`（Rhino 8 Package Manager）。GitHub Release 與 Package Manager **同一份** `.yak`，另附 checksum。不做 RHI。
- **含 Rhino 與 Blender add-on**：正式指令、`.rhp`、產品工具列 RUI、`templates/` 裡的 Sync add-on（含內嵌 import_3dm）。第一次跑任一產品指令拷到「文件\LoopFlow\Rhino to Blender Sync」。
- **不進 yak**：ToolBox（獨立 Blender zip）。
- 畫面名稱：**`loopflow Rhino to Blender Sync`**。檔名型式對齊 `loopflow-2.0.7-rh8_0-win.yak`（例 `loopflow-rhino-to-blender-sync-3.0.0-rh8_0-win.yak`）。
- 開發期仍用 ScriptEditor＋repo；進包後按鈕打正式 `! _RBModels` 等（見 `rhino指令.md`）。

### GitHub tag（不覆寫）

| tag | 意義 |
|---|---|
| `v2.0.0` | 已發布 2.x；永不移動 |
| `v3.0.0` | 第一次公開 3.0 功能版；永不移動、不覆寫 |
| `v3.0.1`… | 之後清單／工具列／說明連結等修補；各 tag 亦不覆寫 |

同一個 tag 代表該次**整份 repo**；yak 含 Rhino 與 Blender add-on。

公開使用說明在 repo 根與 `docs/`（本版；中英）。舊版只存在對應 GitHub tag。Open Docs 開 `main` 的 `docs/README.md`。上架文案在 `wip/docs/readme/`。Package Manager 已上架；Food4Rhino 已送審，待審核通過後再補頁面網址。

### 本機「文件\LoopFlow」戳記

第一次跑任一產品指令，把 yak `templates/` 裡的 Sync **zip** 拷到 `%USERPROFILE%\Documents\LoopFlow\Rhino to Blender Sync\`（不拷開發用資料夾）：

- 戳記＝套件版號；版號相同且已有檔則完全不動。
- 版號不同或沒有戳記：先清空該產品資料夾，再拷這版官方 zip 與戳記（這次有拷才開資料夾）。不刪整個 `Documents\LoopFlow`。
- 那不是專案工作資料夾。工作仍以已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2B/` 為準。
- 不自動寫入 Blender addons；使用者用 Install from Disk 裝 zip。

### 建置路徑（G02）

對齊 LoopFlow：Rhino 8 Script Editor **新增專案**另存 `wip/packaging/g02-spike/loopflow-rhino-to-blender-sync.rhproj`（手寫會被拒絕）→ `RhinoCode.exe project build` → 刪自動 `.rui` → 複製 `wip/docs/toolbar/` 產品 RUI／`icon.png` → `yak.exe build`。進包時 RUI 檔名必須與 `.rhp` 相同（例 `LoopFlow R2B.rui`），Rhino 才會自動載入工具列。指令 `language` 必須是物件，不可字串 `"python3"`。腳本第一行 `#! python 3`。Libraries＝`wip/src`。七支指令見 `指令名稱.txt`。
