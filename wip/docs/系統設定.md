## 執行時路徑

- **設定與即時檔**：已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2B/`。未存檔即停。
- 測檔環境變數：`LOOPFLOW_R2B_WORKFILES_ROOT`（雙機路徑見工作區 `工作檔路徑.md`）。**不**用 Dropbox `exchange/` 當執行時根。
- Consumer 找專案：指標檔預設＋手動覆寫（XF-ED-04＝C）。指標可在 `%APPDATA%`；語系等電腦偏好也放 AppData，不進專案設定根。
- 即時檔不提交 Git。
- 程式不寫死某台電腦的 Dropbox 絕對路徑。

## 開發測試入口

### Rhino

- 按鈕巨集：`rhino指令.md` → `wip/src/rhino/entrypoints\`（檔案後續建立；入口只轉交、無業務邏輯）。
- 暫定指令：`R2B_Models`、`R2B_Camera`、`R2B_Light`、`R2B_Open`。

### Blender（測試用 Sync add-on 空殼）

- 使用**隔離** Blender **5.2.1** profile 安裝；**package ID 與 2.x 不同**，不覆蓋已發布 `LoopFlow_import_3dm`／Toolkit。
- 開發期先做一個 **測試用 Sync add-on**：N-Panel 先排齊暫定按鈕（Models 更新、Camera 開／關自動同步、Camera 手動一次、Light、Open／路徑／Health 等），operator 可為空殼（顯示「尚未實作」即可）。
- 對齊 Rhino `entrypoints` 與 XF-ED-03＝B：先有入口、後接功能；業務邏輯不寫在面板層。
- 正式／日常測法＝啟用 add-on＋面板／timer；Scripting 貼 py 僅臨時除錯，不是產品入口。
- maintainer：`Chihyu Tsai`（見上表）。
