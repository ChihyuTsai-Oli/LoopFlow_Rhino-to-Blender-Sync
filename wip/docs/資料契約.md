# LoopFlow R2B 3.0 — 資料契約

本文件是 3.0 指令、設定、檔名、JSON／3DM schema、Blender 識別字與跨軟體資料契約的權威來源。前期決策過程在 `前期規劃/`；**已決原則寫於此**。欄位級細節於 A01 盤點後加厚；無明顯衝突時實作可調細節，衝突先改 `前期規劃/資料生態決策表_三家建議.md` 再回寫本檔。

## 契約狀態

- 套用版本：R2B `v3.0.0`
- 舊版參考：`v2.0.0`
- 階段：**原則已定；盤點表與 schema fixtures 未完成**
- 開發期指令清單：`rhino指令.md`
- 3.0 核心只使用本契約；v2 相容留在獨立 migration

## 共通規則

- 每種資料有 `schema_version`、producer、document／session 身分。
- Consumer **僅 parse＋apply 成功**才更新「已套用」狀態。
- pending → validate → atomic；失敗不碰 last-good。
- 來源 `.3dm` 在成功／取消／失敗／中斷後狀態還原（含 `doc.Modified`）。
- 未知 schema 版本：停止並說明，不猜測。
- Machine／API 名稱用穩定英文；顯示可用中文。
