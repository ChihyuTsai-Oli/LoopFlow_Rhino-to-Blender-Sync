## 共通規則

- 每種資料有 `schema_version`、producer、document／session 身分。
- Consumer **僅 parse＋apply 成功**才更新「已套用」狀態。
- pending → validate → atomic；失敗不碰 last-good。
- 來源 `.3dm` 在成功／取消／失敗／中斷後狀態還原（含 `doc.Modified`）。
- 未知 schema 版本：停止並說明，不猜測。
- Machine／API 名稱用穩定英文；顯示可用中文。

## Camera／Light JSON 形狀（2.x 實測；3.0 將加 schema 欄）

**Camera（2.x）** — Rhino 寫、Blender `update_viewport_from_json` 讀：

```json
{
  "location":  {"x": 0, "y": 0, "z": 0},
  "direction": {"x": 0, "y": 0, "z": 0},
  "up":        {"x": 0, "y": 0, "z": 0},
  "lens": 50.0
}
```

- 單位／軸：Rhino 原生；Blender 乘 `rhino_cam_scale`（預設 `0.01`）、鏡頭乘 `rhino_cam_lens_mult`（預設 `1.80`）。
- 3.0 必加：`schema_version`、producer、document／session；寫入改 pending→validate→atomic。

**Light（2.x）**：

```json
{
  "points": [
    {"guid": "<str>", "type": "<terminal-layer>", "loc": [x, y, z]}
  ]
}
```

- `type`＝圖層 FullPath 末段（燈具模板名）。
- 3.0：本輪仍只位置＋guid／type；**零符合點 → 不寫檔、不清 consumer**（ED-06／07）。

## ED-08 必須保留清單（重複同步）

Blender **Update Models**（`update_mats=False`）與 Light 對齊時，3.0 **必須保留**：

| 項目 | 擁有者 | 備註 |
|---|---|---|
| 已調材質槽／材質資料（非 Import 覆寫路徑） | Blender | Import（`update_mats=True`）可覆寫；Update 不可 |
| Collection exclude／viewport／render 顯隱 | Blender | 2.x 已 capture／restore |
| Object hide／display_type | Blender | 同左 |
| `Lighting Fixtures`／`Lighting` 內**模板**物件 | 使用者／Blender | 不因 sync 刪模板 |
| 燈 empty 下**非** `INST_*` 子物件 | 使用者 | 2.x 用 `recovered_rhino_guid` 保全 |
| 使用者手動加的非 sync 物件／collection | 使用者 | 不進 orphan 清除 |
| Toolkit／非 Sync 建立的命名 | Toolkit | 主鏈不改 |

**允許被 sync 覆寫／重建**：帶 `rhino_guid` 的 sync empty 位置、`INST_*` 實例（對齊模板）、Rhino-owned 幾何（Update 路徑下的 mesh 等，細節 A03）。

**禁止**：因空 Light JSON 或空 `points` 清掉上表保留項（ED-07）。

## 2.x 缺陷 → 3.0 約束（不重開 ED）

| 缺陷 | 3.0 約束 |
|---|---|
| Models 選完圖層後 `_SelAll`（含 safety box） | **禁止 `_SelAll`**；明確物件 ID（ED-01） |
| Models 先 `os.remove` 再 Export | pending→validate→atomic；失敗不動 last-good |
| Models 開中間檔清理、再 Open 回工作檔 | 不靠開檔還原；來源 snapshot／restore；零意外 `Modified` |
| Models 空選仍可能靠 safety box「成功」 | 空範圍＝阻擋 |
| Light 空點仍寫空清單；Blender 級聯刪 orphan | 空／錯層＝不發布、不清燈 |
| Camera／Light JSON 直接 overwrite | atomic 發布 |
| Blender camera：mtime 變就 apply、壞 JSON 可能半套 | 僅 parse＋apply 成功才更新狀態 |
| `sc.sticky.has_key`（Py2 風格） | CPython 3.9 標準 API |
| ResetPath 寫死 AppData Data | XF-ED-04＝C：指標＋手動覆寫 |
| Sync UI 嵌在 importer fork | Sync｜importer｜Toolkit 分開 |
