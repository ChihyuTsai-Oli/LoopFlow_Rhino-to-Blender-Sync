# LoopFlow ToolBox — 架構

目的：加／改／刪功能時只動一包程式與一份規格，不拆整包 add-on。

## 目錄

```text
wip/src/blender/loopflow_toolbox/
  __init__.py                 # bl_info、父面板 ToolBox、轉交 features
  features/
    __init__.py               # FEATURES 清單
    export/
    rename/
    selection/
```

規格：`wip/docs/toolbox/功能/<id>.md`，`<id>` 必須與 `FEATURES` 字串相同。

## 清單

`features/__init__.py` 的 `FEATURES` 元組＝啟用順序＝子面板由上到下。漏列的目錄不會 register。

每個功能包必須提供：

- `register()`／`unregister()`
- 一個子面板（`bl_parent_id = LOOPFLOW_TOOLBOX_PT_root`）
- 自己的 operators；`bl_idname` 前綴 `loopflow_toolbox.`
- 若掛了 RNA／Scene 屬性，只在本包 `unregister` 裡 `del`

父面板只負責 bar 名 **ToolBox**。不要在父 `draw` 裡畫各功能按鈕。

## 加功能

1. 新增 `features/<id>/`（含 `register`／`unregister`）
2. 把 `<id>` 加進 `FEATURES`
3. 新增 `功能/<id>.md`（按鈕、輸入、副作用、失敗、相依）
4. 測例若寫死清單，一併更新

## 改功能

只改該包與對應 md。不要為了改 Export 去動 Rename。

## 刪功能

1. 從 `FEATURES` 移除
2. 刪 `features/<id>/`
3. 刪 `功能/<id>.md`
4. 確認沒有殘留 RNA（尤其 Collection／Scene 動態屬性）

刪光所有功能時，N 面板仍可留下空的 **ToolBox** bar。這是允許的。

## 禁止

- 從 ToolBox import Sync／`foundation`／`import_3dm`
- 把 ToolBox 放進 yak `templates/`
- 為了新功能去改 Sync 的 N 面板
- 在根 `__init__.py` 堆積業務 operator（應放在功能包）
