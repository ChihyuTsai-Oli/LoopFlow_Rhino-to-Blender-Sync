# LoopFlow ToolBox — 實作總覽

Blender 側獨立 add-on。不進 Rhino `.yak`、不參與 Models／Camera／Light 同步。細節見同目錄其餘文件。

## 目前狀態

- 版號：`(1, 0, 0)`；公開 tag **`toolbox-1.0.0`**（不設成 repo latest）
- 目標 Blender：**5.2.1**（與 R2B Sync 相同 Portable）
- 來源：2.x `releases/LoopFlow_Toolkit/`（唯讀）；3.0 在 `wip/src/blender/loopflow_toolbox/` 重建
- 安裝：傳統 Add-ons zip（Install from Disk），**不**走 Extensions、**不**經 Rhino 第一次指令拷檔

## 產品邊界

```text
LoopFlow ToolBox（獨立 add-on）
  N 標籤 LoopFlow → bar ToolBox
    Export Tools
    Rename Tools
    Selection Tools

不讀 _LoopFlow_Config、不讀 live／models 交換檔
不 import Sync、foundation、import_3dm
```

Sync 缺席或版本不同，不得擋住 ToolBox；反之亦然。

## 完成關卡（本批）

1. 本目錄契約／架構／流程／功能規格可依模組增刪。
2. add-on 可 register；三組功能已自 2.x 搬入。
3. 可打獨立 zip；yak 建置不含 ToolBox。
