# LoopFlow ToolBox — 資料契約

凍結使用者可見名稱與 package 識別字。功能行為見 `功能/`。

## 已凍結名稱

| 角色 | 值 |
|---|---|
| N 面板標籤 | `LoopFlow` |
| N 面板 bar | `ToolBox` |
| 子面板（英文） | `Export Tools`、`Rename Tools`、`Selection Tools` |
| Add-on 列表名 | `LoopFlow ToolBox` |
| package 目錄 | `loopflow_toolbox` |
| operator 前綴 | `loopflow_toolbox.*` |
| 按鈕／report | 英文（對齊 2.x 原文） |

2.x 的 `exporttools.*`／`lighthouse.*`、bar `LoopFlow Toolkit`、RNA `r2b_export_selected` **不沿用**。

## 父／子面板 ID

| 角色 | `bl_idname` |
|---|---|
| 父 bar | `LOOPFLOW_TOOLBOX_PT_root` |
| Export | `LOOPFLOW_TOOLBOX_PT_export` |
| Rename | `LOOPFLOW_TOOLBOX_PT_rename` |
| Selection | `LOOPFLOW_TOOLBOX_PT_selection` |

子面板 `bl_parent_id`＝父 bar。刪模組＝少一個子面板，父 bar 仍在。

## RNA（僅 Export 模組擁有）

- `Collection.loopflow_toolbox_export_selected`（Bool）
- `register` 時掛、`unregister` 時 `del`；不得留在 Collection 型別上

## 與 Sync 的命名隔離

`_Ins`、`COL_FINAL_*` 是 ToolBox 的改名／編組習慣，**不是**同步契約。主鏈不讀、不改這些名字。
