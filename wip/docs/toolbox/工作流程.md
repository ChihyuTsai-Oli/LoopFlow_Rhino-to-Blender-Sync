# LoopFlow ToolBox — 工作流程

在 **OBJECT** 模式使用。N 面板：**LoopFlow → ToolBox**。逐步輸入見 `功能/`。

## 安裝（正式 zip）

1. Edit → Preferences → Add-ons → **Install from Disk**
2. 選 `loopflow_toolbox-1.0.0.zip`
3. 列表勾選 **LoopFlow ToolBox**
4. 不要用 Get Extensions；不要與 2.x `LoopFlow Toolkit` 同時啟用同一場景當正式專案

開發：跑 `wip/tools/link_dev_toolbox.ps1`，啟用同名 add-on（junction 指向 repo）。

## 與 Sync 並存

同一個 LoopFlow 標籤會同時看到 **Rhino to Blender Sync** 與 **ToolBox**。兩邊可單獨開關。ToolBox 不設 Work Folder、不開設定根。

## 建議順序（可跳）

1. **Selection**：Group／Re-Group 整理層級
2. **Rename**：Collection 與物件命名（含 `_Ins`）
3. **Export**：頂層 Collection 出 USDZ（根物件先移到原點再還原）

失敗時該按鈕停在該次操作；不連動其他模組。Ctrl+Z 可還原多數步驟；Export 中途例外時位置可能未還原，用 Undo。
