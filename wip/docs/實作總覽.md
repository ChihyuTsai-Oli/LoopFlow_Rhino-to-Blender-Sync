## 產品邊界

```text
Rhino Producer（Models／Camera／Light／Open）
        ↓ 安全發布檔案
Blender Sync Integration（第一方 UI／timer／state／operators）
        ↓ 呼叫唯一入口
import_3dm fork（只做 3DM→Blender conversion）
Toolkit（獨立；3.0 核心不擴充、不阻塞主鏈）
```

- 不把 Blender UI 或 conversion 塞進 Rhino 指令。
- 不把同步 UI 長在 converter 核心。
- R2B／R2O 只共用文件層安全語彙，不共用 runtime package。
- Shader Editor **Box Projection** 是著色輔助，不進上列同步鏈、不寫 UV。

## 重構模式

- 乾淨重建、正式發布一次切換；開發中不要求相容 2.x。
- 不在核心長期保留 v2 alias、雙寫、compatibility wrapper。
- 升級集中於獨立 migration。
- 3.0 使用隔離 scripts、設定根、Blender profile／package ID。
