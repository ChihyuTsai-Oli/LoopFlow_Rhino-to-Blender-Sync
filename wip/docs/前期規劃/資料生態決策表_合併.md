# R2B 3.0 — 資料生態決策表（合併建議）

> 由 `資料生態決策表_三家建議.md` 產生（2026-08-27）。三欄 AI 建議已併為「整合建議」；「你的決定」照原表。權威來源仍是原表；本檔僅供閱讀。詳見同目錄 `操作流程模擬.md`。


本檔為閱讀用合併稿。裁決請改原檔 `資料生態決策表_三家建議.md`，再重跑 `merge_decision_table.py`。

## 使用方式

- 直接改「你的決定／說明」：可寫「採用」「不採用」「採用，但…」或自訂規則。
- 請保留 `XF-*`／`R2B-*` 編號，方便追蹤與回寫。
- ND 若標「由某 ED 統一裁決」，只填上方對應列。
- 你確認後，AI 回寫命名契約、系統設定、使用說明、Roadmap／PROGRESS；**確認前不寫正式產品功能碼**。

### 整合建議怎麼讀

- 一欄濃縮 Grok／Claude／Codex；標明強度票數與方向。
- 以最右欄「你的決定」為準；衝突時以決定欄覆寫建議方向。

### AI 建議強度

| 強度       | 意義                            |
| -------- | ----------------------------- |
| **強烈建議** | 關係資料不斷鏈、可復原、避免靜默錯誤；不採用需同等安全替代 |
| **一般建議** | 可改，但會增加規則／操作／維護成本             |
| **輕鬆建議** | 不影響核心鏈，可依習慣調整                 |
