A. 開案

  1. 1. 隔離 2.x／3.0（不同 Blender profile；不同設定根）。
  2. 2. 開啟已存檔 .3dm（未存檔則發布停）。
  3. 3. R2B_Open＋Health（路徑、三通道 last-good、Blender Sync Folder）。
  4. 4. Blender：指標或手動路徑（手動優先）。

---

B. Models → Camera → Light

B1. Models

  1. 5. 選專案圖層（可沿用上次成功）。
  2. 6. 彈出類別勾選：預設勾選 Mesh 等模型類；Point、Curve 預設不勾（可臨時勾）。顯示將匯出物件數。
  3. 7. R2B_Models：依物件 ID 在暫存處理；無視隱藏／鎖定／凍結當可見；禁止 _SelAll。
  4. 8. pending → validate → atomic model.3dm；來源狀態還原。
  5. 9. Blender 更新模型；保留材質等 Blender-owned。空範圍＝阻擋。

B2. Camera

  1. 10. 透視視角；執行後可開啟／關閉自動同步，或手動推一次。
  2. 11. live/camera.json atomic；套用成功才更新狀態。

B3. Light

  1. 12. Point 在 LightLayer；只同步位置＋ GUID。
  2. 13. 無點／圖層錯 → 不發布空清單、不清 Blender 燈。
  3. 14. 第一輪齊備。

---

C. 第二輪

  1. 15. 改幾何 → Models → Blender 更新。
  2. 16. 改視角／燈點 → Camera／Light。

---

D. 失敗停點（摘要）

未存檔停；Models 失敗仍在原工作檔；Light 空層不清燈；JSON 半寫不 apply。

E. 最小可測

Camera 按鈕 → Health／log → Light → Camera atomic → Models → 拆 Blender fork。

F. 不涵蓋

Toolkit／Auto Basic Material；自動升級；能量顏色回寫 Rhino。
