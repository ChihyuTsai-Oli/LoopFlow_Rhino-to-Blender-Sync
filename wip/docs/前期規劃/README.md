## 權威順序

1. 日常開工仍讀 `wip/docs/` 六份 SSOT（使用說明、系統設定、命名契約、重構計畫、Roadmap、PROGRESS）。
2. **命名／schema／工作流尚未定案時**：以本資料夾決策表為「尚待確認」唯一來源；不要同時在藍圖與決策表寫兩套答案。
3. 使用者確認後，AI 回寫命名契約、系統設定、使用說明與 PROGRESS；衝突以回寫後的 SSOT 為準。
4. 本資料夾與現行 `_R2B_*.md` 文字衝突時，若決策表尚未裁決 → 先問使用者；若已裁決並回寫 → 以 SSOT 為準。

## 不要做

- 不要在決策表未確認前寫正式產品功能碼。
- 不要把本資料夾當公開使用者指南。
- 不要另建第二份決策表或在聊天外散落未回寫的裁決。
