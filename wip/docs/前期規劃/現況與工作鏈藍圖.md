## 產品一句話

Rhino → 安全發布檔案 → Blender 消費：Models（3DM）、Camera、Light（本輪以 Point 位置為主）。

## 已定案邊界（細節見決策表 E 區）

- 目標 `v3.0.0`；`main` 凍 2.x；整合 `v3-development`
- 乾淨重建、發布時一次切換；核心不留 v2 雙寫
- 四邊界：Rhino Producer｜Blender Sync｜`import_3dm` fork｜Toolkit（不擴充、不阻塞）
- 執行時設定／即時檔：工作檔旁 `_LoopFlow_Config/loopflow_R2B/`
- 來源 `.3dm` 零變更；Models／Camera／Light 採 pending → validate → atomic last-good
- 與 R2O 只共用文件層安全語彙，不共用 runtime package

## 現行 2.x 觀察（待盤點成 3.0 契約）

- 安裝在 `%APPDATA%\...\scripts\LoopFlow_R2B\`；設定 `R2B_Path.txt`；Camera／Light JSON 在 AppData `Data\`
- 指令習慣名：Models、Camera、Light、Open（開發暫定檔名見 `../rhino指令.md`）
- Blender 端有 collection／operator／timer 等命名；3.0 canonical 尚未填入盤點表
- Light：重構文件寫本輪只保留 Point 位置同步；PROGRESS golden 仍提到能量／顏色——以決策表釐清

## 建議工作鏈（草案，非正式流程契約）

```text
開案（.3dm 已存檔）
→ Open／Config（路徑與設定）
→ Models 發布 3DM（pending → validate → last-good）
→ Camera／Light 發布 JSON（atomic；consumer parse+apply 成功才更新 state）
→ Blender 端更新模型／對齊相機／燈光
→ 失敗保留 last-good；來源檔不變
```

各步可否獨立執行、失敗 UI、選取範圍等 → 見決策表。
