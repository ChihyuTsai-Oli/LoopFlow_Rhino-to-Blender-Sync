# LoopFlow R2B 3.0 — 工作流程

本文件是 3.0 主操作順序與失敗停點的權威來源。細節模擬與決策過程見 `前期規劃/操作流程模擬_合併.md`；若衝突以本檔與 `資料契約.md` 為準。

## 操作主線

**Models → Camera → Light**（可獨立重跑單一通道）。

開發時：**Rhino 端與 Blender 端同一通道同批實作**，才能測試。

## 開案

1. 隔離 2.x／3.0（不同 Blender profile、設定根、package ID）。
2. 開啟**已存檔** `.3dm`（未存檔則發布停）。
3. `R2B_Open`＋Health：路徑、三通道 last-good、Blender 同步資料夾（指標或手動；手動優先覆寫）。
4. Blender：讀指標或手動路徑（XF-ED-04＝C）。

## Models

1. 選**專案圖層**（可記上次成功為預設）。
2. 彈出**幾何類別勾選**：Point／Curve **預設不勾**；其餘預設勾；顯示將匯出物件數。
3. 依明確物件 ID 處理；無視隱藏／鎖定／凍結當可見；**禁止 `_SelAll`**。
4. pending → validate → atomic 寫入 models 輸出；失敗不碰 last-good。
5. 來源文件狀態還原。
6. Blender 更新模型；保留 Blender-owned 材質等（保留清單見契約，A01 明細）。
7. 空範圍＝阻擋，不假裝成功。

## Camera

1. 透視視角。
2. **執行後可開啟／關閉自動同步**；亦可手動推一次。
3. atomic 寫入 `live/camera.json`（檔名待契約凍結；角色不變）。
4. Blender 僅在 parse＋apply 成功後更新狀態。

## Light

1. Point 在 LightLayer；本輪**只同步位置**（可附 GUID 供對齊）。
2. 無符合點／圖層錯：**不發布空清單、不清 Blender 燈**。
3. 自動同步開關語意同 Camera（ED-02）。

## 第二輪

改幾何 → Models；改視角／燈點 → Camera／Light。可只跑變更通道。

## 失敗停點（摘要）

| 情況 | 行為 |
|---|---|
| 未存檔 | 停止發布 |
| Models 失敗 | 仍在原工作檔；last-good 不動 |
| Light 空層 | 不清 Blender 燈 |
| JSON 半寫 | consumer 不 apply、不更新已套用狀態 |
| 取消／中斷 | 來源還原；不留半套 |
