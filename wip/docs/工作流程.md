# LoopFlow R2B 3.0 — 工作流程

本文件是 3.0 主操作順序與失敗停點的權威來源。細節模擬與決策過程見 `前期規劃/操作流程模擬_合併.md`；若衝突以本檔與 `資料契約.md` 為準。A01 已對照 2.x 行為；標「3.0 修正」處依已決 ED，不重開決策。

## 操作主線

**Models → Camera → Light**（可獨立重跑單一通道）。

開發時：**Rhino 端與 Blender 端同一通道同批實作**，才能測試。

## 開案

1. 隔離 2.x／3.0（不同 Blender profile、設定根、package ID）。
2. 開啟**已存檔** `.3dm`（未存檔則發布停）。
3. `R2B_Open`＋Health：路徑、三通道 last-good、Blender 同步資料夾（指標或手動；手動優先覆寫）。
4. Blender：讀指標或手動路徑（XF-ED-04＝C）。

**2.x 對照**：`LiveLink_R2B_Open.py` 僅開 Config／DataFolder／DebugLog，無 Health；設定在 AppData `R2B_Path.txt`。3.0 改專案旁 `_LoopFlow_Config/loopflow_R2B/`。

## Models

### 3.0 步驟

1. 選**專案圖層**（可記上次**成功**為預設）。
2. 彈出**幾何類別勾選**：Point／Curve **預設不勾**；其餘預設勾；顯示將匯出物件數。
3. 依明確物件 ID 處理；無視隱藏／鎖定／凍結當可見；**禁止 `_SelAll`**。
4. pending → validate → atomic 寫入 models 輸出；失敗不碰 last-good。
5. 來源文件狀態還原（含 `doc.Modified`）；**不**靠 Open 中間檔還原工作檔。
6. Blender 更新模型；保留清單見 `資料契約.md` ED-08。
7. 空範圍＝阻擋，不假裝成功。

### 兩端 I/O（A01）

| | Rhino producer（2.x → 3.0） | Blender consumer（2.x → 3.0） |
|---|---|---|
| 觸發 | 跑 Models 腳本／`R2B_Models` | Import Models／Update Models |
| 輸入 | 已存檔 doc；使用者選圖層；Config | `rhino_update_path` → `.3dm` |
| 輸出 | `ModelDir`+`ModelFile`（2.x `R2B.3dm`）→ 3.0 `models/model.3dm` | 場景幾何／材質（依 update_mats） |
| 副作用（2.x） | 解鎖全圖層、`_SelAll`、刪舊檔、Open 中間檔清理、SaveAs、再 Open 工作檔 | capture／restore 顯隱；可 merge 重複材質 |
| 3.0 修正 | 明確 ID；atomic；來源 snapshot／restore；空＝擋 | Sync 獨立套件；Update 遵守 ED-08 |
| 失敗／取消 | 2.x：可能已刪輸出檔或改過中間檔；3.0：last-good 不動、來源還原 | 檔不存在→取消；不更新「已套用」 |

## Camera

### 3.0 步驟

1. 透視視角；工作檔須已存檔。
2. Rhino：`R2B_Camera`＝開／關自動同步（再按一次關）；`R2B_Camera_Push`＝手動推一次（ED-02）。
3. atomic 寫入 `_LoopFlow_Config/loopflow_R2B/live/camera.json`（`schema_version=1`）。
4. Blender：**作業資料夾**＝工作檔同層（或按重新整理自動偵測）；**Camera Auto On／Off／Push Once**；僅 parse＋apply 成功才更新已套用狀態。

### 兩端 I/O（A01→D01）

| | Rhino | Blender |
|---|---|---|
| 觸發 | `R2B_Camera` toggle；`R2B_Camera_Push` | `camera_auto_on`／`off`／`push`；timer `0.03`s |
| 輸入 | ActiveView CameraLocation／Direction／Up／35mm lens | 作業資料夾 → `…/live/camera.json` |
| 輸出 | 設定根 `live/camera.json`（atomic） | viewport 位置／鏡頭 |
| State | sticky event＋路徑快取 | `r2b3_cam_*` wm keys |
| 3.0 | atomic；可手動推；標準 sticky | parse＋apply 成功才記 applied |

## Light

### 3.0 步驟

1. Point 在 LightLayer **子層**（預設 `R2B_LT_Points::燈具名`）；本輪**只同步位置**（附 GUID／type）。父層本身不算合法。
2. 無符合點：手動 Push **不發布**；自動同步若本 session 先前有點，發 `clear=true` 讓 Blender 整組刪 empty／燈／燈具（ED-07）。
3. Rhino：`R2B_Light`＝開／關自動同步；`R2B_Light_Push`＝手動推一次（ED-02）。
4. Blender：作業資料夾同 Camera；**Light Auto On／Off／Sync Lights**；無對應模板時不留裸 empty；orphan／clear 刪整組。

### 兩端 I/O（A01→D02）

| | Rhino | Blender |
|---|---|---|
| 觸發 | `R2B_Light` toggle；`R2B_Light_Push`；Add／Delete／Replace／Undelete／**換圖層（ModifyObjectAttributes）** | `light_auto_on`／`off`／`sync_lights`；timer `0.25`s |
| 輸入 | 全場景 Point，過濾 LightLayer（含子層邊界） | 作業資料夾 → `…/live/light.json` |
| 輸出 | `live/light.json`（atomic；`schema_version=1`） | 更新／建立 `RH_*` empty、`INST_*`；可刪 orphan |
| 2.x 問題 | **零點仍寫空 `points`** | 空 active_guids → 級聯刪帶 `rhino_guid` 的 empty |
| 3.0 修正 | 空＝不寫檔（ED-07） | 空／無效／不發布 → **不清燈**；保留非 `INST_*` 子物件 |

## 第二輪

改幾何 → Models；改視角／燈點 → Camera／Light。可只跑變更通道。

## 失敗停點

| 情況 | 行為 |
|---|---|
| 未存檔 | 停止發布（Models／寫入設定根的通道） |
| Models 失敗／取消／中斷 | 仍在原工作檔；last-good 不動；來源還原 |
| Models 空範圍 | 阻擋，不假裝成功 |
| Light 空層／無符合點 | 不發布；不清 Blender 燈 |
| JSON 半寫／parse 失敗 | consumer 不 apply、不更新已套用狀態 |
| 取消／中斷 | 來源還原；不留半套 pending |

## 磁碟示意（開發暫定檔名；A02 凍結）

```text
_LoopFlow_Config/loopflow_R2B/
  config.json / r2b.log
  live/camera.json | camera_pending.json
  live/light.json  | light_pending.json
  models/model.3dm | model_pending.3dm | （last-good 同角色）
```

**2.x 對照（AppData）**：`R2B_Path.txt`、`R2B_Camera_Sync.json`、`R2B_Light_Sync.json`、工作檔旁或 `ModelDir` 的 `R2B.3dm`。

## 不涵蓋（3.0 核心）

Toolkit 擴充、Auto Basic Material、自動升級混用、能量／顏色回寫 Rhino。
