## Golden workflow 基準

- Models：**有材質**＝`RBModels` ↔ Sync／Update；**無材質**＝`RBObjects` ↔ Import Objects（選檔）。Block 關聯複製 **家中通過**。
- Camera：自動同步 Modified 直接覆蓋；Blender timer 0.016s；**家中跟隨通過**。
- Light：刪非燈物件不寫檔；燈點變更 debounce＋差分套用。圖層／collection 範例見 `工作流程.md`。
- Importer：已內嵌於 Sync。
- N 面板：3D 標籤 `LoopFlow`、bar `Rhino to Blender Sync`。Shader Editor 同標籤、bar `Box Projection`。各 Sync 按鈕有英文懸停說明。
- Box Projection：Load PBR Maps；World／Object；幾何法線；Blend 0 轉 45° 不發黑；新建節點寬 ×1.5；不寫 UV。**家中通過**。
- Open：`RBOpen` 四顆按鈕 Config／live／models／Docs；Blender **Open / Health** 懸停＝摘要、左鍵開設定根；**Open Docs** 開 GitHub 入口。**家中通過**。
- 發布：yak 含 Rhino 與 Blender zip；Package Manager 畫面名 `loopflow Rhino to Blender Sync`；版號 **`3.0.0`**；`v3.0.0` 永不移動。換版清空「文件\LoopFlow\Rhino to Blender Sync」再拷官方 zip。
